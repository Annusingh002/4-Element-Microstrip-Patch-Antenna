# 4-Element Microstrip Patch Antenna Array

## Overview
Designed and simulated a **4-Element Microstrip Patch Antenna Array** using **CST Studio Suite** to achieve high gain, good impedance matching, and directional radiation characteristics for THz wireless communication applications.

## Software Used
- CST Studio Suite

## Key Features
- 4-element microstrip patch antenna array
- Corporate feed network
- High-gain directional radiation
- Excellent impedance matching

## Simulation Results
- **Operating Frequency:** 0.3515 THz
- **Return Loss (S11):** -24.29 dB
- **VSWR:** ≈ 1.1
- **Peak Gain:** High directional gain of approx. 12.7dBi

## Applications
- THz Wireless Communication
- 6G Networks
- Radar Systems
- Satellite Communication
